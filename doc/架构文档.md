## 一、项目概述

SPZX（尚硅谷甄选）是一个基于 **若依(RuoYi-Cloud) v3.6.3** 的分布式微服务电商平台，采用前后端分离架构。

### 技术栈

| 分类 | 技术 | 版本 |
|------|------|------|
| 语言 | Java | 21 |
| 框架 | Spring Boot | 3.0.5 |
| 微服务 | Spring Cloud | 2022.0.2 (Kilburn) |
| 微服务 | Spring Cloud Alibaba | 2022.0.0.0-RC2 |
| 注册中心 / 配置中心 | Nacos | Server |
| 网关 | Spring Cloud Gateway | 响应式(WebFlux) |
| 流量控制 | Sentinel | Dashboard: 192.168.6.100:8858 |
| ORM | MyBatis-Plus | 3.5.3.1 |
| 连接池 | Druid | 1.2.21 |
| 缓存 | Redis | — |
| 消息队列 | RabbitMQ | — |
| 认证 | JWT + Redis 会话 | jjwt 0.9.1 |
| 分布式事务 | Seata | — |
| API 文档 | Knife4j | 4.1.0 |
| 文件存储 | FastDFS + MinIO | 8.5.2 |
| 定时任务 | Quartz | — |
| 监控 | Spring Boot Admin | 3.0.4 |
| 支付 | Alipay SDK | 4.8.73.ALL |

## 四、认证与鉴权体系

### 4.1 认证流程（四层安全防护）

```
外部请求
    │
    ▼
[第一层] Gateway AuthFilter — JWT 令牌解析 + Redis 会话校验
    │  白名单路径（security.ignore.whites）跳过
    │  非法请求返回 HTTP 401
    │
    ▼  注入请求头: user_id, username, user_key
    │
[第二层] HeaderInterceptor — 提取请求头 → SecurityContextHolder (Transmittable ThreadLocal)
    │  自动刷新 Redis 会话（< 2h 剩余时续期，总 TTL 12h）
    │
    ▼
[第三层] @PreAuthorizeAspect — AOP 拦截注解
    │  @RequiresLogin          — 必须登录
    │  @RequiresPermissions("xxx:xxx:list")  — 权限码校验
    │  @RequiresRoles("admin") — 角色校验
    │  @Logical.AND / @Logical.OR  — 多值逻辑
    │
    ▼
[第四层] @InnerAuthAspect — 内部调用安全
    │  校验请求头 from-source = "inner"
    │  外部请求该头已被 Gateway 清除，无法伪造
```

### 4.2 双端认证架构

```
                    spzx-auth (9200)
                    ┌─────────────────────┐
  /login ──────────►│ TokenController     │──► RemoteUserService ──► spzx-system (后台管理员)
  /logout           │ (后台管理端)         │
  /refresh          └─────────────────────┘
  /register
                    ┌─────────────────────┐
  /h5/login ───────►│ H5TokenController   │──► RemoteUserInfoService ──► spzx-user (前台会员)
  /h5/logout        │ (H5 移动端)          │    支持短信验证码登录
  /h5/register      └─────────────────────┘
```

### 4.3 Feign 调用上下文传递

```
服务 A (收到请求)                   服务 B (被调用)
┌──────────────────┐              ┌──────────────────┐
│ HeaderInterceptor│              │ @InnerAuth 切面   │
│ 提取 headers ──┐ │              │ 校验 from-source  │
│ 存入 ThreadLocal│ │ FeignRequest │ = "inner" ✓      │
│                │ │ Interceptor  │                  │
│                │ │ 透传:        │                  │
│                ├─► user_id     ├─►                │
│                │   username                     │
│                │   user_key                     │
│                │   Authorization                │
│                │   X-Forwarded-For              │
└──────────────────┘              └──────────────────┘
```

### 5.3 关键调用场景详解

**H5 首页加载 `/index`：**
```
H5 前端 → Gateway → spzx-channel (IndexController)
                        ├── RemoteCategoryService.tree()      → spzx-product  ← 获取三级分类树
                        └── RemoteProductService.getTopSale()  → spzx-product  ← 获取热销商品
                        返回聚合后的 Map<String, Object>
```

**H5 商品详情 `/item/{skuId}`：**
```
H5 前端 → Gateway → spzx-channel (ItemController)
                        └── RemoteProductService.getProductSku(skuId)     → spzx-product
                            RemoteProductService.getProduct(id)           → spzx-product
                            RemoteProductService.getSkuPrice(skuId)       → spzx-product
                            RemoteProductService.getProductDetails(id)    → spzx-product
                            RemoteProductService.getSkuSpecValue(id)      → spzx-product
                            RemoteProductService.getSkuStock(skuId)       → spzx-product
                        返回聚合后的商品详情 VO
```

**H5 登录 `/h5/login`：**
```
H5 前端 → Gateway → spzx-auth (H5TokenController)
                        └── H5LoginService.login()
                              ├── Redis: 校验验证码 (phone:code:xxx)
                              ├── RemoteUserInfoService.getUserInfo()     → spzx-user
                              ├── 密码校验 (BCrypt)
                              ├── RemoteUserInfoService.updateUserLogin()  → spzx-user
                              └── TokenService.createToken()              → 返回 JWT
```

**后台登录 `/login`：**
```
管理前端 → Gateway → spzx-auth (TokenController)
                        └── SysLoginService.login()
                              ├── RemoteUserService.getUserInfo()         → spzx-system
                              ├── 密码校验 (BCrypt)
                              └── TokenService.createToken()              → 返回 JWT
```

**下单结算：**
```
H5 前端 → Gateway → spzx-order
                        ├── RemoteCartService.xxx()         → spzx-cart    ← 获取购物车
                        ├── RemoteProductService.xxx()      → spzx-product ← 商品/价格/库存校验
                        ├── RemoteUserAddressService.xxx()  → spzx-user    ← 收货地址
                        └── RabbitService.sendMessage()     → RabbitMQ     ← 发送库存/支付消息
```

## 十、关键设计说明

### 10.1 spzx-channel 的 BFF 定位
- 专门为 H5 移动端设计的前端聚合层
- **不连接数据库**，所有数据通过 Feign 从 spzx-product 获取
- 对前端暴露简洁 API（`/index`、`/item/{id}`、`/list`、`/category/tree`、`/brand`）
- 隐藏了后端微服务的复杂性，可以在一个请求中聚合多个微服务的数据

### 10.2 `@InnerAuth` 内部调用安全
- 所有服务间暴露的接口都标记 `@InnerAuth`
- 切面 `InnerAuthAspect` 校验请求头 `from-source` 必须等于 `"inner"`
- 外部请求经过 Gateway 的 `AuthFilter` 时该请求头已被移除
- 这是比简单的 IP 白名单更安全的内部调用保护机制

### 10.3 JWT + Redis 双重会话
- JWT 只携带轻量声明（user_id, username, user_key），本身不可撤销
- 真实会话状态（LoginUser, permissions, roles）存储在 Redis（TTL 12h）
- 网关通过 Redis 校验会话存在性，实现集中式会话失效
- 自动续期：剩余时间 < 2h 时自动延长

### 10.4 代码规范
- 统一返回体：`R<T>`（Feign 调用）/ `AjaxResult` + `TableDataInfo`（Controller）
- Controller 统一继承 `BaseController`
- Service 继承 MyBatis-Plus 的 `ServiceImpl<Mapper, Entity>`
- 分页使用 PageHelper（`startPage()` → `getDataTable(list)`）
