# SPZX 业务模块、业务流程与接口调用链路梳理

> 基于源码(spzx-modules 各服务 + spzx-api 域 + spzx-common)梳理。
> 说明:各服务数据源在 Nacos `application-dev.yml` 配置(多数据源),通常每个业务服务一个 MySQL 库;文档确认 `spzx-system` 使用 `spzx-system` 库,Docker 初始库为 `ry-cloud`。下表"库"按"每服务一个 MySQL 库"标注。

## 二、核心业务流程图(H5 商城交易主链路)

```
① 登录/注册   H5 ──网关──> spzx-auth(/h5/login、/h5/register) ──Feign──> spzx-user
② 逛商品      H5 ──网关──> spzx-channel(/index、/category/tree、/item/{skuId}、/list/skuList、/brand/getBrandAll)
                     └─Feign─> spzx-product
③ 购物车      H5 ──网关──> spzx-cart(/addToCart、/cartList、/checkCart、/deleteCart、/clearCart)  [纯 Redis]
④ 结算        H5 ──网关──> spzx-order(/orderInfo/trade) ──Feign──> spzx-cart(getCartCheckedList)
⑤ 下单        H5 ──网关──> spzx-order(/orderInfo/submitOrder)
                ├─Feign─> spzx-cart(deleteCartCheckedList)
                ├─Feign─> spzx-product(getSkuPriceList 校验价格、checkAndLock 锁库存)
                ├─Feign─> spzx-user(getUserAddress 收货地址)
                └─RabbitMQ──> 延迟关单消息(15min 未支付自动取消/解锁)
⑥ 支付        H5 ──网关──> spzx-payment(/alipay/submitAlipay/{orderNo})
                └─> Alipay 支付宝 WAP 支付 → 异步回调 /alipay/callback/notify(RSA2 验签)
                └─RabbitMQ──> payment.pay 支付成功消息
⑦ 支付→扣库存  payment ──MQ(payment.pay)──> spzx-order(processPaySucess 置已支付)
                └─MQ(spzx.minus)──> spzx-product(productService.minus 扣减库存)
⑧ 超时关单    MQ(spzx.cancel.order 延迟)──> spzx-order(processCloseOrder 置取消)
                └─MQ(spzx.unlock)──> spzx-product(productService.unlock 解锁库存)
```

## 三、各模块接口调用链路(Controller → Service → 库/表/Feign/MQ)

### 1) spzx-product(商品)
管理端(需权限):
- `GET /product/list` → IProductService.selectProductList → ProductMapper → **product**
- `POST /product` / `PUT /product` / `DELETE /product/{ids}` → insert/update/delete → **product**(+ 事务内更新 **product_sku**、**product_details** 等)
- `GET /product/{id}` → selectProductById → **product** + **product_sku** + **product_details**
- `GET /product/updateAuditStatus/{id}/{auditStatus}`、`/product/updateStatus/{id}/{status}` → **product**

面向 H5(均为 `@InnerAuth`,由 channel/order 等内部 Feign 调用):
- `GET /product/getTopSale` → getTopSale → **product_sku**
- `GET /product/skuList/{pageNum}/{pageSize}` → skuList → **product_sku**
- `GET /product/getProductSku/{skuId}` → **product_sku**
- `GET /product/getProduct/{id}` → **product**
- `GET /product/getSkuPrice/{skuId}`、`POST /product/getSkuPriceList` → **product_sku**(sale_price/market_price)
- `GET /product/getProductDetails/{id}` → **product_details**
- `GET /product/getSkuSpecValue/{id}` → 规格值(product_sku + product_spec)
- `GET /product/getSkuStock/{skuId}` → **sku_stock**
- `POST /product/checkAndLock/{orderNo}` → checkAndLock → **sku_stock**(Redis 预占/锁定)+ **product_sku**

其它商品管理(子控制器):`CategoryController`(/category)、`BrandController`(/brand)、`CategoryBrandController`(/categoryBrand)、`ProductSpecController`、`ProductUnitController`。

### 2) spzx-user(会员 / H5)
- `GET /userInfo/list`、`/userInfo/export` → **user_info**
- `GET /userInfo/{id}`、`GET /userInfo/getUserAddress/{userId}` → **user_info**、**user_address**
- `POST /userInfo/register`(@InnerAuth) → **user_info**
- `GET /userInfo/info/{username}`(@InnerAuth, 供 auth 登录) → **user_info**(含角色/权限? 会员无 RBAC)
- `POST /userInfo/updateUserLogin`(@InnerAuth) → **user_info**(更新登录 IP/时间)
- `GET /userInfo/getLoginUserInfo` → 当前登录用户 + 收货地址
- `GET /userAddress/list|/userAddress/{id}`、`POST/PUT/DELETE /userAddress` → **user_address**
- `GET /region/treeSelect/{parentCode}` → **region**
- `GET /sms/sendCode/{phone}` → 生成验证码 → Redis `phone:code:{phone}` + 调阿里云短信

### 3) spzx-order(订单 / 结算)
- `GET /orderInfo/trade`(结算)→ getOrderTrade
  - Feign → spzx-cart `getCartCheckedList`(**Redis 购物车**)
  - 计算金额,生成 tradeNo(Redis `user:tradeNo:{userId}`)
- `POST /orderInfo/submitOrder`(下单)→ submitOrder
  - Lua 脚本去重(Redis `user:tradeNo:{userId}`)
  - Feign → spzx-product `getSkuPriceList`(价格校验 → **product_sku**)
  - Feign → spzx-product `checkAndLock`(锁库存 → **sku_stock**)
  - Feign → spzx-user(收货地址 → **user_address**)
  - 落库 **order_info**、**order_item**、**order_log**(@Transactional)
  - Feign → spzx-cart `deleteCartCheckedList`(删购物车)
  - RabbitMQ 发延迟关单消息(spzx.cancel.order / 15min)
- `GET /orderInfo/{id}`、`/orderInfo/list`、`/orderInfo/export` → **order_info**、**order_item**
- `GET /orderInfo/getOrderInfo/{orderId}` → **order_info**
- `GET /orderInfo/getByOrderNo/{orderNo}`(@InnerAuth, 供 payment)→ **order_info** + **order_item**
- MQ 消费者:`processPaySucess`(置已支付 order_info)+ 发扣库存消息;`processCloseOrder`(置取消 order_info)+ 发解锁库存消息

### 4) spzx-payment(支付)
- `POST /alipay/submitAlipay/{orderNo}` → submitAlipay
  - savePayment:Feign → spzx-order `getByOrderNo` → **order_info**/**order_item**;落 **payment_info**
  - 调支付宝 `alipay.trade.wap.pay`(WAP 支付表单)
- `POST /alipay/callback/notify`(异步回调)→ RSA2 验签 → updatePaymentStatus → **payment_info** + RabbitMQ 发 `payment.pay` 支付成功消息

### 5) spzx-cart(购物车,纯 Redis)
- `GET /cart/addToCart/{skuId}/{skuNum}`、`/cart/cartList`、`/cart/deleteCart/{skuId}`、`/cart/checkCart/{skuId}/{isChecked}`、`/cart/allCheckCart/{isChecked}`、`/cart/clearCart` → 全部操作 Redis(按 userKey 的购物车哈希)
- `GET /cart/getCartCheckedList/{userId}`、`/cart/updateCartPrice/{userId}`、`/cart/deleteCartCheckedList/{userId}`(@InnerAuth, 供 order)→ Redis

### 6) spzx-channel(H5 BFF,无库,纯 Feign)
- `GET /index` → Feign product:分类树(category)+ 热销(getTopSale)
- `GET /category/tree` → Feign product 分类树(**category**)
- `GET /brand/getBrandAll` → Feign product 品牌(**brand**)
- `GET /item/{skuId}` → Feign product:getProductSku、getProduct、getSkuPrice、getProductDetails、getSkuSpecValue、getSkuStock(聚合商品详情)
- `GET /list/skuList/{pageNum}/{pageSize}` → Feign product skuList(**product_sku**)

### 7) spzx-auth(认证,无库)
- `POST /auth/login`(管理端)/ `/h5/login`(前台)→ SysLoginService / H5LoginService
  - 校验验证码(网关)+ IP 黑名单(Redis)
  - Feign → spzx-system `/user/info/{username}`(管理端)或 spzx-user `/userInfo/info/{username}`(前台)
  - 密码校验、写 Redis `login_tokens:{uuid}`、签发 JWT
- `POST /auth/register` / `/h5/register` → 注册
- `GET /code`(网关)→ 图形验证码
- `POST /auth/logout` / `/h5/logout` → 删 Redis 会话

### 8) spzx-system(系统管理,15 表)
Controller → Service → Mapper(MyBatis 或 MyBatis-Plus)→ 各 `sys_*` 表。典型:
- `SysUserController /system/user/**` → **sys_user**、**sys_user_role**、**sys_role**、**sys_menu**(权限)
- `SysRoleController /system/role/**` → **sys_role**、**sys_role_menu**、**sys_role_dept**(数据权限)
- `SysMenuController /system/menu/**` → **sys_menu**(动态路由 getRouters)
- `SysDeptController /system/dept/**` → **sys_dept**(树)
- `SysDict*Controller /system/dict/**` → **sys_dict_type**、**sys_dict_data**
- `SysConfigController /system/config/**` → **sys_config**
- `SysPostController /system/post/**` → **sys_post**
- `SysNoticeController /system/notice/**` → **sys_notice**
- `SysOperlogController /system/operlog/**` → **sys_oper_log**;`SysLogininforController /system/logininfor/**` → **sys_logininfor**
- `SysUserOnlineController /system/online/**` → Redis 在线用户(无表)
- 供 auth 的内部接口(@InnerAuth):`GET /user/info/{username}`、`POST /user/register`、`POST /operlog`、`POST /logininfor`

### 9) spzx-gen(代码生成)、spzx-job(定时任务)
- gen:`GenTableController /tool/gen/**` → **gen_table**、**gen_table_column**(Velocity 模板生成代码)
- job:`SysJobController /monitor/job/**` → **sys_job**、**sys_job_log**;`SysJobLogController /monitor/jobLog/**` → **sys_job_log**

## 四、涉及库表汇总(按库)

> 每个带库服务一个 MySQL 库(库名在 Nacos 配置,惯例 `spzx-<模块>`,文档确认 system=`spzx-system`);Docker 默认 `ry-cloud`。

| 库 | 表 |
|---|---|
| spzx-product(商品库) | product、product_sku、product_details、category、category_brand、brand、product_spec、product_unit、sku_stock |
| spzx-user(会员库) | user_info、user_address、region |
| spzx-order(订单库) | order_info、order_item、order_log |
| spzx-payment(支付库) | payment_info |
| spzx-system(系统库) | sys_user、sys_role、sys_menu、sys_dept、sys_dict_type、sys_dict_data、sys_config、sys_post、sys_notice、sys_oper_log、sys_logininfor、sys_user_role、sys_role_menu、sys_user_post、sys_role_dept |
| spzx-gen(代码生成库) | gen_table、gen_table_column |
| spzx-job(任务库) | sys_job、sys_job_log |
| Redis(无库表) | `login_tokens:*`(会话)、`captcha_codes:*`(验证码)、`phone:code:*`(短信)、`user:tradeNo:*`(结算号)、购物车哈希(cart)、`pwd_err_cnt:*`(密码锁定)、`sys_config:sys.login.blackIPList` 等 |

| order | RemoteUserAddressService.getUserAddress | spzx-user | user_address |
| payment | RemoteOrderInfoService.getByOrderNo | spzx-order | order_info/order_item |
| auth | RemoteUserService.getUserInfo/registerUserInfo | spzx-system | sys_user/role/menu |
| auth | RemoteUserInfoService.getUserInfo/updateUserLogin/register | spzx-user | user_info |
| auth | RemoteLogService(operlog/logininfor) | spzx-system | sys_oper_log/sys_logininfor |
| channel | RemoteCategoryService.tree、RemoteProductService.getTopSale/getProductSku/... | spzx-product | category/product_sku/... |
| product(Rabbit 消费) | —(MQ spzx.minus/spzx.unlock) | — | sku_stock |
| order(Rabbit 消费) | —(MQ payment.pay/cancel.order) | — | order_info |
