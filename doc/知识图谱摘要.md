## 五、直接查询 JSON(不依赖仪表盘)

`spzx-parent/.ua/knowledge-graph.json` 是标准 JSON,可编程读取。例如列出所有 `class` 节点或某模块文件:

```python
import json
d = json.load(open(r"C:\Users\11931\IdeaProjects\spzx-parent\.ua\knowledge-graph.json", encoding="utf-8"))
# 全部类节点
cls = [n for n in d["nodes"] if n["type"] == "class"]
# 某文件的所有类/函数
mod = [n for n in d["nodes"] if "spzx-product" in n.get("filePath", "")]
# 边的结构
edges = d["edges"]
```

> 说明:导入(imports)边较稀疏——由于扫描未含 importMap 且多数 Java 批的 `batchImportData` 为空,跨文件结构以 file/class/function 节点 + `implements`/`calls`/`configures` 等语义边承载;若需补齐 Java 导入边,可基于源码再跑一次导入抽取。
